Data Breach Notification Assistant — Motor Multi-Jurisdiccional

Derecho + Ciberdefensa

Motor que evalúa las obligaciones de notificación de un incidente con impacto en datos personales cruzando el caso contra tres marcos normativos en paralelo: Ley 25.326 (Argentina/AAIP), GDPR (UE, arts. 33/34) y CCPA/CPRA + Cal. Civ. Code § 1798.82 (California). Traduce hechos técnicos de un incidente en una respuesta jurídica estructurada y con plazos concretos por jurisdicción.

  • Motor de reglas por jurisdicción: un mismo incidente puede activar más de un marco normativo a la vez; el motor determina si aplica, si corresponde notificar a la autoridad de control y a los titulares, y en qué plazo, para cada una.
  • Doble interfaz sobre un único núcleo: CLI interactiva y por flags (Click) para uso local/scripting, y API REST (FastAPI) con Swagger para integración.
  • Informes de auditoría: generación de reportes estructurados en JSON y PDF, listos para respaldar una decisión de notificación real ante un incidente.
Python FastAPI Click (CLI) Ley 25.326 GDPR CCPA/CPRA

Proyecto de portafolio con fines educativos y de demostración técnica; la lógica normativa está simplificada y no constituye asesoramiento legal.
